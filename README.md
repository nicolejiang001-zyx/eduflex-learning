# Eduflex Learning

请帮我用 React 和 Tailwind CSS 搭建一个极简、现代的单页网站框架。网站名称是：EduFlex Learning 灵动教育。

主色调： 权威的深蓝色 (Navy Blue) 与活力的温暖橙色 (Warm Orange)。请保持大量留白，设计干净、具有高级感。

页面只需包含以下 4 个基础区块：

首屏 (Hero Section)：

大标题：量身定制学习方案，双母语不是奢望！

副标题：100% 中国本土严选师资，服务海外华裔家庭与成人。

按钮：一个醒目的橙色按钮“获取免费专属试听”。

核心优势 (Features Grid)： 用 3 个带图标的基础卡片横向排列，标题分别是：

100% 满意承诺

全球经验 本土严选

按需购课 零捆绑

定制方向 (Learning Paths)： 用 3 个简洁的卡片展示，标题分别是：

低龄趣味启蒙 (4-7岁)

中小学高效提升 (8-14岁)

VCE 与成人实用定制 (15岁+)

底部表单 (Simple Contact)： 一个极简的留资框，包含：姓名、邮箱、下拉菜单（选择年龄段），以及一个“立即预约”的提交按钮。

请确保整体排版圆润 (rounded corners)、带有轻微的高级阴影 (soft shadows)，并完美适配手机端。
